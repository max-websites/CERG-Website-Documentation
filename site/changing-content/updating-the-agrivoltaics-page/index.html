Updating the agrivoltaics page

This guide will walk you through the process of updating the agrivoltaics page on the CERG website. Most of this is also a duplicate from updating the homepage.

You can edit the Agrivoltaics page through this link below.

Prerequisite

You must be signed into your SFU account and have access to AEM in order to make changes. If you do not have access, please contact Andy to request access.

Go to Agrivoltaics page on AEM

Change the banner image

Prerequisite

You have already uploaded the image to AEM that you want added to the banner. If you haven't done this yet, please follow the steps in Uploading new photos and documents.

  1. Double click on the banner image or right click and select Edit.
  2. Select the Image tab.
  3. Drag and drop a new image into the Image field from the sidebar.
  4. Press the Crop button to crop the image to a 3:1 (Banner) aspect ratio.
  5. If you'd like to include a caption, select the Advanced Image Properties tab and enter your text in the Description text field.
  6. Press the OK button and Activate the page to save your changes.

Update text content

  1. Right click on the text you want to edit and select Edit.
  2. Make your changes in the text editor that appears.
  3. Use the formatting buttons a the top of the editor to format your text, add links, or add images.
  4. Press the OK button and Activate the page to save your changes.

Text with {{ }}

Don't edit text inside {{ }} — it's a variable placeholder auto-filled by the site, and editing it breaks the component.

If that text needs to change (e.g., event, working paper, or news article info), update it via the documentation for that content type instead; changes will automatically reflect on the Agrivoltaics page.

Change photos in the photo gallery

Each photo gallery on our website is its own folder in AEM's DAM (Digital Asset Manager). To change the photos in the gallery, you will need to upload new photos to the folder and delete old ones.

Go to the Agrivoltaics image gallery folder in DAM

  1. Go into DAM and find the image(s) you want to add to the gallery.
  2. Select the image(s), right click, and select the Copy button
  3. Navigate to the Agrivoltaics image gallery folder and select Paste to add the image(s) to the gallery.
  4. Reorder, delete, or edit the images in the gallery as needed.
  5. Make sure you activate the image(s) to save your changes.
  1. Follow the instructions for uploading new images to DAM first.
  2. Add a caption to the images if you want to (see instructions below).
  3. Copy the images to the Agrivoltaics image gallery folder using the instructions in the first tab.
  4. Make sure you activate the image(s) to save your changes.

Adding captions

If you want to add captions to the images in the gallery, you can do so by editing the image properties in DAM.

  1. Right click on the image and select Open.
  2. Enter your text in the Description text field.

Update the video feed

Currently the Agrivoltaics page has a YouTube video feed that automatically pulls in videos from the Agrivoltaics playlist on CERG's YouTube channel. If you want to change the videos that appear on the feed, add new videos to that playlist.

Agrivoltaics YouTube playlist

Visit YouTube's documentation for more information on how to add videos to a playlist .

Playlist sorting

Currently, the videos in the playlist are sorted by "Date added (newest)". If you want to change the order of the videos, you can change the sorting method in the playlist settings .

If you want to change this feed's behaviour (i.e. showing specific videos), follow these instructions.

Add a team member

Prerequisite

You have already uploaded the image to DAM under the CERG team folder and have created a team member page under CERG Team .

If you want to add a new team member to the Meet the team section, you can copy and paste an existing member card and edit the information:

  1. Right click on an existing team member card (i.e. Omri Haiven's) and select Copy.
  2. Right click on the Drag components and assets here section that's below the existing cards and select Paste.
  3. Change the information in the new card by right clicking on it and selecting Edit. Make sure to change the name, description, link text and URL, and image.
    1. Ensure the image is a square image (1:1 aspect ratio) and is cropped to the face of the team member.
  4. Press the OK button and Activate the page to save your changes.

Edit Current Partnerships section

As the current partnerships section is just a text block you can edit the text by right clicking on it and selecting Edit. More detailed instructions are available here.

Add/remove a sponsor

Prerequisite

In order to ensure proper sizing for all logos, please run your image through this image resizer before uploading it to DAM.

Then you can proceed with uploading the logo to DAM under the Logos folder .

  1. Ensure you have properly resized the logo and uploaded it to DAM under the Logos folder.
  2. Duplicate an existing sponsor card by right clicking on it and selecting Copy.
  3. Right click on the Drag components and assets here section that's below the existing cards and select Paste.
  4. Edit the new card by right clicking on it and selecting Edit.
  5. Change the image to the new sponsor's logo by dragging and dropping it from the sidebar.
  6. Go to the Advanced tab and change the Link to field to the sponsor's website.
  7. Press the OK button and Activate the page to save your changes.

Place sponsor cards in the first two columns

Only place sponsor cards in the first two columns. The third column is reserved to preserve the mobile layout.
